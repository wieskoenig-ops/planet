# planet.emergenz.art

Essays über Kipppunkte (deutsch unter `/`, englisch unter `/en/`). Statisches HTML auf GitHub Pages.

- Texte: `_build/essays/de/<id>.html` und `_build/essays/en/<id>.html`, Metadaten in `_build/build.py`
- Bauen: `python3 _build/build.py`, prüfen: `python3 _build/linkcheck.py`
- Hintergrundmotive: `motive/*.js`, Laufzeit `motiv.js`
